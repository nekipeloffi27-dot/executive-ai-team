# Researcher — source quality

## When to apply
Any research output.

## Rules
- **Always include URL** for every claim from a search result. No URL = doesn't count.
- **Date the claim**: "Reddit r/skincareaddiction, 2025-09" not just "Reddit".
- **Distinguish hypothesis from fact**:
  - "Fact: Lóvi has 1.2M downloads (App Store, sensor tower data)" ✓
  - "Hypothesis: Lóvi growth driven by TikTok virality" ✓
  - "Lóvi is winning because TikTok" — too confident, mark as hypothesis ✗
- **Don't invent numbers.** If sensor tower says 1.2M and another says 800K — report both, name source.

## Source tiers
- Tier 1: official company data, government stats, peer-reviewed
- Tier 2: industry reports (Sensor Tower, Statista, App Annie)
- Tier 3: tech press (TechCrunch, VC), Reddit, forum discussions
- Tier 4: random blogs — use only as supplement, never as primary
