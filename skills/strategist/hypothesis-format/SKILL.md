# Hypothesis format

## When to apply
Any time you propose a strategic move, experiment, or product direction shift.

## Format

```
Гипотеза: [одно предложение, falsifiable]
Основание: [конкретные данные/ресерч/паттерны — не вкусовщина]
Эксперимент: [как проверим за <6 недель]
Метрика успеха: [конкретное число, не "стало лучше"]
Срок: [сколько ждём результат]
Стоимость провала: [что потеряем если гипотеза не подтвердится]
```

## Example

```
Гипотеза: Quiz-first onboarding (как у Lóvi) повысит wall-conversion на 15-25%.
Основание: Lóvi App Store reviews показывают высокое engagement до auth. Их retention сильнее средних в категории (источник: Sensor Tower).
Эксперимент: A/B тест с 50/50 split на 4 недели, 1000+ юзеров в каждой ветке.
Метрика успеха: Conversion to signup ≥ +15% (currently ~28%).
Срок: 6 недель (включая разработку quiz-flow).
Стоимость провала: 2 недели разработки + минус для wall-конверсии в варианте B.
```
