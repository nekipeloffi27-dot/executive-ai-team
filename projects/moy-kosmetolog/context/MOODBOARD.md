# Moodboard — moy-kosmetolog

## Визуальные референсы (направление, не плагиат)

- **Aesop** (aesop.com) — теплый минимализм, типографика, образованный тон
- **Tatcha** (tatcha.com) — чистая структура, доверие через сдержанность
- **Notion docs** — спокойная информационная плотность
- **Linear (linear.app)** — точные пропорции, edge-case respect

## Композиция
- Воздух важнее наполнения. Лучше пустое поле, чем decorative element без смысла.
- Сетка 12 col на desktop, simple stack на mobile (PWA — mobile-first)
- Информационная иерархия чёткая: hero → CTA → secondary info → details

## Фото и иллюстрации
- Реальная кожа в reference photos (не глянец)
- Минималистичные иконки (Phosphor / Lucide стиль), не decorative
- Никаких stock-photo «улыбающихся азиаток с кремом»

## Анимации
- Subtle. Fade-in, slide-in длительностью 200-300ms.
- Никаких bouncy / springy
- Loading: shimmer placeholder, не spinning circle
